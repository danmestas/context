ctx is the tool that saves your coding-agent sessions and project documents so they can be searched later. This page lists what it needs you to settle, one row each, with the evidence beside it. This page changes nothing by itself. Nothing is chosen for you: pick row by row, or press Use suggestions in a section to take the suggestion on every row that has one. Your choices become a short list at the foot of the page, and ctx page apply runs that list.

Your choices

One line per choice that changes something. Copy them into a file and run ctx page apply FILE to see what would be done; add --yes to do it. Lines beginning with # are left for you: ctx does not edit your Claude Code settings, so removing a hook is yours to do.
